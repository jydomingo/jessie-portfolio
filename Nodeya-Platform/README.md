# Nodeya Platform

Nodeya Platform is the shared foundation supporting current and future Nodeya products.

[Read the full case study](CASE_STUDY.md)

## Portfolio scope

- Identity and single sign-on
- Roles, permissions, and API access
- Subscriptions and notifications
- Audit logs and file storage
- API gateway
- Service status

## Technology profile

.NET APIs, OIDC/JWT, SSO, audit services, shared packages, and API gateway architecture.

## Repository notice

This folder is a public portfolio showcase only. Platform source code, credentials, security configuration, infrastructure definitions, and internal architecture details are not included.
