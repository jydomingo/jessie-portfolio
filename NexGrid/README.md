# NexGrid

NexGrid is a solar monitoring application for real-time operational visibility across multiple sites.

[Read the full case study](CASE_STUDY.md)

## Portfolio scope

- Real-time dashboards
- Device and site management
- Alerts and notifications
- Historical energy data
- Reporting
- Multi-site access
- Role-based permissions
- SignalR and MQTT integration

## Repository notice

This folder is a public portfolio showcase only. Product source code, device credentials, telemetry data, infrastructure configuration, and customer information are not included.
