# Nexora

Nexora is a multi-organization commerce and inventory application designed around traceable operational workflows.

[Read the full case study](CASE_STUDY.md)

## Portfolio scope

- Access and organization management
- Product catalog and inventory ledger
- Purchasing and receiving
- Sales issuance and returns
- Transfers and stock counts
- Reporting and audit evidence
- Forecasting foundations

## Technology profile

.NET, React, TypeScript, PostgreSQL, REST APIs, OIDC, role-based access, and organization-scoped workflows.

## Repository notice

This folder is a public portfolio showcase only. Product source code, credentials, business data, and deployment configuration are not included.
